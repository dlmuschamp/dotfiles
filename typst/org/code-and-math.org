* Keep writing in Org
Use Org headings and Shift-Tab in Neovim to navigate this file. Use *bold*,
/italic/, =Org code=, ~verbatim~, or Typst-style `inline_code(x)` in prose.
Code is printed, never executed. Leading spaces and nested indentation survive
PDF export. Tab characters in code use four-column tab stops.

* Mathematics with Typst syntax
Inline math has tight delimiters: $sqrt(x^2 + y^2)$ and $alpha + beta$.

$ sum_(k=1)^n k = (n(n+1))/2 $

$
mat(1, 2; 3, 4) vec(x, y) = vec(x + 2y, 3x + 4y)
$

** A worked example
The average is $overline(x) = (sum_(i=1)^n x_i)/n$.
Write Typst math, not LaTeX commands, inside these dollar signs.

* MATLAB
#+begin_src matlab :exports code :eval never
values = [1, 2, 3];
for k = 1:length(values)
    if values(k) > 1
        fprintf('value: %g\n', values(k));
    end
end
#+end_src

* Python
#+begin_src python :exports code :eval never
def mean(readings):
    if not readings:
        raise ValueError("at least one reading is required")
    return sum(readings) / len(readings)
#+end_src
