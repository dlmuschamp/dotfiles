# 💤 LazyVim

Start with the [write-up quick reference](WRITING-QUICKREF.md) for daily keys,
Org structure, Typst math, code snippets, and PDF export.
Full setup and behavior are documented in [ORG-WRITING.md](ORG-WRITING.md).
For local MATLAB sign-in, CLI scripts, matching image paths, and explicit
generate-and-embed commands, see [MATLAB and Org plots](../docs/matlab-org-plots.md).
Tool setup and image embedding must not rewrite your original calculations.

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.
